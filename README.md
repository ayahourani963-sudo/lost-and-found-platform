# 🔍 منصة المفقودات والموجودات | Lost & Found Platform

![Status](https://shields.io)
![Type](https://shields.io)
![License](https://shields.io)

**منصة المفقودات والموجودات (Lost & Found Platform)** is a modern, responsive frontend web application designed to help users browse and report lost or found items through an intuitive interface.

---

## ✨ Features

- **Clean & Intuitive UI:** User-friendly interface to easily navigate between Lost and Found listings.
- **Post Item Interface:** Interactive forms to submit lost or found item details (title, category, date, location, and image preview).
- **Search & Filtering:** Instant client-side search and filtering by item status (`Lost` / `Found`) and category.
- **Responsive Design:** Fully adaptable layout that works smoothly on desktop, tablet, and mobile screens.
